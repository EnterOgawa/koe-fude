# KoeFude 1.0.0 リリースノート

2026/11/13 / Shunji Ogawa / MIT License

Windows 11 x64向けの日本語専用版です。既定の音声認識と話者分けはPC内で行います。
インストーラーは現在の利用者向けに管理者権限なしで導入し、ZIP版は一式を展開して使えます。
モデル本体を含みません。必要なモデルはアプリの準備画面から明示取得します。
署名状態と各ファイルのSHA-256は配布物の `PACKAGE.json`、配布ファイル全体は `SHA256SUMS` で確認してください。

## 主な機能

- M4A・WAV・MP3・FLACをドラッグまたはCtrl+Oで追加し、複数ファイルを順番に処理します。
- 日本語Parakeet CTC FP32 / 自動（GPU優先・CPU）が既定です。軽量CPU・Whisper系も選べます。
- 音声から話者を推定し、時刻と話者別の色で本文を表示します。話者名変更・全文コピー・UTF-8 TXT/SRT/VTT保存に対応します。
- 音声一覧と結果、保存に成功した音声モデル・文字起こし/話者設定を次回起動にも復元します。
- 任意の有料OpenAI APIによる文章改善と原文比較、明示選択の音声API、部分原文の保存と手動再開を提供します。起動だけでは音声や本文を送りません。
- モデル不足時に準備画面を案内します。APIキーやモデル・単価は文章改善タブで設定します。
- 起動時に更新情報を一回確認します。一般設定でOFFにでき、手動確認もできます。更新取得・終了して更新は利用者が選んで行います。
- 本文・音声・入力ファイル名・パス・APIキーを含まないローカル診断ログを最大10MiBで保存し、自動送信しません。

## 導入とデータ

対応CPUはSSE4.2・BMI2を備えたx64です。アプリ利用にPython・Node.js・ブラウザーserverの導入は不要です。
CUDA/VulkanのGPU経路は対応driverを使います。モデル準備後のローカル処理はオフラインで利用できます。
デスクトップアイコンは導入時の任意選択で、初回は未選択です。インストーラーはアプリを強制終了・自動再起動しません。
アンインストールでは音声・書き出した結果・履歴・設定・モデルキャッシュ・保存APIキーを削除しません。

## 確認範囲と制限

音声認識と話者分けには誤りがあります。重要な発言や数値は原音と照合してください。
API利用料は別途かかり、取消し・通信切断後の課金停止を保証しません。
旧履歴と設定は読取り互換を保持します。旧言語値の保存互換は維持しますが、新規認識と画面は日本語固定です。

搭載RAM16GB級を開発上の最低対象とし、GPUメモリ12GiB以内を目標にしています。
実環境のinstall/upgrade/uninstall、16GB実機、独立12GiB、全GPU/全モデル、高DPI、本文精度/DERの未測定条件は残っています。
製品ソースのビルド確認と署名・配布物の検証は、これらの実環境・精度受入とは別です。
