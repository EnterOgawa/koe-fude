# KoeFude 1.1.0 リリースノート

2026/11/17 / Shunji Ogawa / MIT License

Windows 11 x64向けの日本語専用版です。録音開始時刻と連続する同じ話者の見出しに対応しました。
モデル本体は同梱せず、準備済みモデルによる既定の音声認識と話者分けはPC内で行います。

## 変更点

- 音声一覧の右クリックから「録音開始時刻を設定…」を開き、半角の`HH:mm`で音声ごとの開始時刻を設定・解除できます。
- 発言開始位置を足した時計時刻を話者の隣へ表示します。分未満は切り捨て、日を跨ぐ場合は`00:10 (+1日)`のように区別します。日付やタイムゾーンは設定しません。
- 同じ一人の連続発言を一つの見出しへまとめ、本文の順序と改行、話者名と色を保ちます。別話者・不明・複数話者を跨いでまとめません。
- TXT保存・全文コピーにも同じ見出しを使います。SRT/VTTの字幕時刻は音声先頭からの相対時刻のままです。
- 開始時刻は履歴に保存し、同じ音声の明示再文字起こしへ引き継ぎます。時刻設定だけで再認識やAPI送信は始まりません。
- 対応する元行が確定していない旧API改善文や自由全文には時刻を推測して付けません。音声APIの話者投影も元送信窓の共通時刻を使い、part固有の発言時刻は作りません。

## 導入と履歴の互換性

インストーラーは現在の利用者向けに管理者権限なしで導入できます。ZIP版はフォルダーへ一式を展開して使います。
署名状態と各ファイルのSHA-256は同梱の`PACKAGE.json`、配布ファイル全体は`SHA256SUMS`で確認してください。

旧履歴V1〜V8は開始時刻未設定として読み込めます。1.1.0で保存する履歴V9は旧1.0.0から直接読めません。
旧版へ戻す場合に備えるときは、更新前にアプリを終了し、`%LOCALAPPDATA%\koefude\history`を別の場所へ控えてください。
元音声の時刻・本文・API候補は保持します。

## 確認範囲

音声認識と話者分けは推定です。重要な発言や数値は原音で確認してください。任意のAPI機能には別途利用料がかかります。
実環境のinstall/upgrade/uninstall、16GB実機、独立12GiB、全GPU/全モデル、高DPI、本文精度/DERの未確認条件は引き続き残ります。
