# KoeFude 1.1.2

## 変更点

- 右クリックメニューに、API文章改善を選べない理由を表示します。処理中、文字起こしの全文未確定、保存や設定の確認が必要な場合を区別できます。
- 履歴から再文字起こしするときに元音声が見つからなければ、その理由とファイルの追加し直し方を表示します。
- 話者分離の既定は引き続きSpectralです。「設定…」の「話者」タブから、試用方式のNemotron 3も選べます。Nemotron 3は人数を自動推定し、対応CPUと追加モデルが必要です。

## 更新方法

既にインストールしている場合は、KoeFudeを終了して現在のインストール先へ上書きできます。文字起こし履歴、設定、取得済みモデルは引き継がれます。

- 1.1.1では「設定」→「更新を確認」から進めます。1.0.0や1.1.0で履歴のエラー「H3」が表示される場合は、手動で上書きしてください。
- 手動で更新する場合は、この版の `KoeFude-1.1.2-windows-x64-cuda-vulkan-setup.exe` を使います。

Windows 11 x64向けのセットアップとZIPを提供します。モデルは、必要になったときにアプリから取得できます。
