# KoeFude 1.1.1 リリースノート

2026/11/17 / Shunji Ogawa / MIT License

未対応の履歴形式がある場合も、元データを保護したままアプリ内更新へ進めるよう修正しました。

## 修正点

- 履歴の読込みがH3（未対応形式）で止まっても、未編集で処理・保存がないことと履歴workerの終了を確認し、「終了して更新」へ進めます。未対応履歴へ書き込みません。
- 更新状況が履歴の「失敗」に隠れる問題を修正しました。「新版あり」「更新準備済み」などを表示し、補助欄に「履歴未読」を残します。
- 履歴と更新情報の到着順が逆でも、更新状況を表示します。
- H3の案内に、設定メニューの更新確認を追加しました。
- 破損・排他使用中・保存失敗・未保存の結果などに対する更新終了の制限は維持します。取得と実行には従来どおり利用者の同意が必要です。

## すでに旧版でH3が表示されている場合

この修正が入っていない1.0.0/1.1.0では、未対応履歴からの更新実行が拒否されます。
その場合だけ、アプリを終了して、この版のインストーラーで現在の導入先へ一度上書き更新してください。
アンインストール、履歴・モデルの削除、再文字起こしは不要です。

履歴形式は1.1.0と同じV9です。旧V1〜V8も読み込めます。新しい形式を旧版へ変換・上書きする処理は追加していません。
録音開始時刻、話者表示、音声認識、API送信条件は1.1.0から変更していません。

## 確認範囲

Debug/Releaseの非表示アプリ試験で、元履歴の全byte/SHA不変・保存0、更新と履歴通知の両順序、同意・取消し・検証失敗、排他解放後のfake起動を確認しました。
実環境のinstall/upgrade/uninstall、16GB実機、独立12GiB、全GPU/全モデル、高DPI、本文精度/DERの未確認条件は引き続き残ります。
