# KoeFudeの使い方

KoeFude 1.0.0はWindows 11 x64向けの日本語版です。配布ファイルは[リリース](https://github.com/EnterOgawa/koe-fude/releases/latest)から取得します。

## 導入

インストーラーは現在の利用者向けに、管理者権限なしで導入できます。
ZIP版は書き込み可能なフォルダーへ一式を展開し、`KoeFude.exe`を開きます。EXEとDLLは同じフォルダーで使ってください。
署名状態とファイルごとのSHA-256は、同梱の`PACKAGE.json`で確認できます。

## モデル準備が必要な場合

起動時に取得済みモデルを検査し、準備済みなら音声を追加してそのまま使えます。必要なモデルが未準備なら、初回起動時にも準備画面が開きます。取得せずに閉じて音声を追加すると準備画面が再び開き、未準備のまま処理は始まりません。
インストーラー・ZIPにモデル本体は含まれていません。準備画面の用途・容量・配布条件を確認して取得し、準備完了後に音声を追加します。別のモデルへ変更する場合は次の手順です。
「設定 → 設定…」の「文字起こし」でモデルを選び、「適用」を押します。
不足するモデルがあれば準備画面が開きます。用途・容量・配布条件・保存先・通信先を確認し、「ダウンロードして使用」を押します。
既定はParakeet CTC FP32、自動（GPU優先 / CPU）、話者分けONです。起動時に取得済みモデルを確認し、準備済みなら操作なしで再利用します。
現行ParakeetのGPU実行はNVIDIA CUDAに対応し、利用できなければCPUで実行します。Intel GPU・NPUによるParakeet実行には対応していません。

## 音声を追加して保存する

1. 音声を本文欄へドラッグするか、「ファイル → 音声を追加…」（Ctrl+O）で選びます。
2. 左の一覧で音声を選び、右側で時刻・話者・本文を読み返します。複数の音声は順番に処理します。
3. 一覧の行を右クリックし、「保存…」からTXT・SRT・VTTを選びます。「全文コピー」や「話者名を変更…」もここで使えます。

一覧と結果は利用者ごとの履歴へ自動保存します。音声認識と話者分けは推定なので、重要な発言や数値は原音で確認してください。[履歴と保存](privacy.md)

## OpenAI APIを選ぶ場合

音声APIと文章改善は任意の有料機能です。共通のAPIキーは「文章改善」タブで設定します。モデル情報・単価の取得中は標準ダイアログが開き、完了すると自動で閉じます。閉じる・Esc・「キャンセル」で情報取得を取り消せます。

キー未設定や情報取得失敗でも、対応済みの文章改善モデル候補を選択・適用できます。候補の表示は利用可能の確認とは別で、キーの利用資格と有効な単価が確認できるまで文章を送信できません。単価とモデル一覧の取得状態は設定内に別々に表示します。

- **文章改善**は同じタブでモデルを設定して「適用」し、対象行の「APIで文章を改善」を選びます。文字起こし全文をOpenAIへ送ります。改善文が保存されると、原文と並べて読めます。
- **音声API**は「文字起こし」で選んで「適用」します。新規投入、再文字起こし、同じ行の「音声APIの続きから再開」で音声区間を送信します。

保存に成功した音声モデルの選択は、次回起動にも復元します。設定内で送信先、モデル、単価を確認できます。送信の条件やキーの扱いは[通信と保存の説明](privacy.md)を参照してください。

## 動作環境と更新

Windows 11 x64、SSE4.2・BMI2対応CPUが対象です。搭載RAM16GB級を開発上の最低対象とし、GPUメモリ12GiB以内を目標にしています。実環境での未確認条件は[リリースノート](releases/1.0.0.md)を参照してください。

入力はM4A、WAV、MP3、FLACに対応し、M4AではAAC-LCを優先しています。コーデックごとの条件は[入力形式の対応表](design/input-acceptance.md)に記載しています。

モデル準備後のローカル文字起こしはオフラインで利用できます。起動時の更新確認は「一般」で切り替え、手動では「設定 → 更新を確認」を使います。新版の取得と実行は利用者の操作で進めます。

開発者向けの[ビルド手順](development.md)も用意しています。
