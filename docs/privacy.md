# 音声・本文・通信と保存

KoeFude 1.0.0 / 2026/11/13 / Shunji Ogawa / MIT License

既定のParakeet/Whisper音声認識と話者分けはPC内で行います。モデル準備後はオフラインで使えます。
音声、本文、入力ファイル名・パス、話者の特徴を既定のローカル処理から外部へ送りません。

## 任意のOpenAI API

文章改善と音声APIは任意の有料機能です。共通のAPIキーを使います。

- **文章改善**は、選択行の「APIで文章を改善」で文字起こし全文をOpenAI Responses APIへ送ります。音声は送りません。改善文を完全に保存した後も原文を保持します。
- **音声API**は、文字起こし設定でOpenAI APIを選択・適用した後の新規投入・再文字起こしと、同じ行の「音声APIの続きから再開」で音声区間を送ります。
  送信先は `https://api.openai.com/v1/audio/transcriptions` です。内部で作ったWAV区間を固定名で送り、元ファイル名・パス、話者名・特徴、過去の本文は送りません。
- 起動、キー登録、履歴表示、行の再選択だけでは音声や本文を送りません。ローカル処理からAPIへ自動で切り替えません。
- 有料操作を自動再送・再開しません。取消しや通信切断は、送信済みの処理の課金停止を保証しません。

設定には送信先・モデル・公式単価・取得日時を表示します。単価の未取得、期限切れ、未掲載を0料金とは扱いません。
音声の料金は送信時間、文章改善の料金はtoken単価によります。概算・観測した使用量と実際の請求額は別です。

モデル情報は `https://api.openai.com/v1/models`、公開価格は `https://developers.openai.com/api/docs/pricing.md` から取得します。
API設定の明示表示・更新、キー適用後、当該API操作に必要な更新時だけ取得し、音声・本文・入力パス・話者情報は含めません。価格取得にはAPIキーを送りません。

## キーの保存

「このWindowsユーザーに保存」は新規登録時OFFです。OFFなら起動中だけ保持し、ONなら現在ユーザーのWindows資格情報として保存します。
通常の設定ファイル、履歴、診断ログにキーを保存しません。登録済みキーは固定の伏せ字で表示し、未編集なら保持します。
入力を変更して「適用」を押した時だけ登録・削除します。

## 履歴と書き出し

音声一覧と文字起こし・採用改善文は `%LOCALAPPDATA%\koefude` 配下へ現在ユーザー用の履歴として自動保存します。
原音声や話者の特徴そのものは履歴へ複製しません。TXT・SRT・VTTは保存先を明示して書き出します。
履歴には入力元の情報や本文が含まれるため、端末・Windowsアカウントの管理にも注意してください。

音声APIが途中で失敗・取消しになっても整合した部分原文は保持し、閲覧・コピー・保存できます。
同じ行の明示再開では、完全応答を保存できた区間を再送しません。送信結果が未確定なら重複課金の可能性を確認してから再開します。
音声全体の一致を確認できない場合や保存に失敗した場合は送信しません。
長い区間の話者対応が不明な部分は中立表示に保ち、APIの語時刻や話者を推測で作りません。

## ローカル診断ログ

通常起動では `%LOCALAPPDATA%\koefude\logs\diagnostics.jsonl` に診断を保存します。
版・時刻・処理段階・固定モデルID・件数/容量・実backend・安全なエラーコードを記録し、各2MiB、現行と旧4世代の計10MiBに制限します。
本文、音声、入力ファイル名・フルパス、ユーザー名、話者名・特徴、APIキー・認証情報、応答本文は記録せず、自動送信しません。
ログの保存障害で文字起こしを停止しません。音声API等の補助ログも本文・秘密情報を含めず、容量を制限しています。

## モデル取得と更新確認

モデル取得は、準備画面に示す用途・容量・配布条件・保存先・通信先を確認して明示実行します。固定サイズとSHA-256を検証してから使います。
モデル本体をインストーラー・ZIPへ同梱しません。

起動時の更新確認は初期ONで、一起動に一回だけ `api.github.com` の固定公開リポジトリ `EnterOgawa/koe-fude` を確認します。
「一般」でOFFにでき、「設定 → 更新を確認」で手動確認もできます。音声・本文・ファイル名・パス・APIキーを送りません。
更新ファイルの取得と「終了して更新」は利用者の明示操作です。取得先は `github.com` / `release-assets.githubusercontent.com` に限定し、標準の署名検証では証明書発行元へ失効情報を照会します。
未公開・オフライン・通信失敗でもローカル文字起こしを続けられます。

アンインストールでは履歴・設定・モデルキャッシュ・保存APIキーを削除しません。
